## Architecture of the Compendium

This compendium is designed as an exhaustive, modular reference manual for hardware hackers, roboticists, off-grid engineers, and creative makers. It catalogues every major class of discarded consumer, commercial, automotive, industrial, and frontier electromechanics—from microscopic voice coils to multi-horsepower traction drives, spatial light modulators, advanced mechanical transmissions, kinematics, rapid field acquisition protocols, community forum lore, and garage-tested fabrication SOPs.
